# AIOps 智能运维与知识助手平台：当前界面设计

## 当前主线

页面已经收口为一组用于值班提效的工作台，而不是彼此割裂的展示稿：

| 页面 | 文件 | 任务 |
| --- | --- | --- |
| 值班工作台 | `workbench-v2.html` | 活动告警队列、同屏诊断、日志、知识依据与告警追问 |
| 故障深挖与交接 | `incident-v2.html` | 告警事实、候选原因、证据链、处理记录、交接报告 |
| 知识助手 | `knowledge-v2.html` | 知识库优先、通用问答、实际召回来源、文档与本地会话 |

根路径 `/` 默认进入值班工作台，`/designs/` 展示当前主线并保留历史页面入口。旧蓝白工作台、故障指挥台和知识助手仍保留，用于回退与对比，但不再作为默认入口。

## 设计目标

让使用者先看到“发生了什么、当前应该做什么”，再展开诊断、证据和知识来源。正式页面不展示没有数据支撑的趋势、准确率或根因概率；模拟告警、模拟日志和模型推断都会明确标注。

## 当前已接入能力

- 工作台读取后端活动告警，支持持续时间筛选、选择告警、同屏诊断、日志查看、知识依据和告警上下文追问。
- 故障深挖支持诊断、证据链、处理记录、交接备注与 Markdown 导出；工作台通过 `sessionStorage` 传递当前告警。
- 知识助手支持知识库优先/通用问答切换，展示真实召回片段与文档内容，支持上传索引和浏览器本地会话。
- 模型使用 OpenAI 兼容中转，当前配置 deepseek-flash；向量化使用 Ollama bge-m3，向量库为 Milvus。

## 数据与边界

- 告警和日志当前为后端 mock，不能表述为真实生产监控。
- 真实 Prometheus 与腾讯云 CLS 查询尚未配置；`cls.mock-enabled:false` 时日志工具会明确提示真实查询尚未实现。
- 检索来源是实际召回片段，不代表每个片段都被最终答案引用；L2 距离不等于可信度。
- 会话和交接内容保存在浏览器本地，不是服务端数据库持久化。

## 正式接入时的数据契约

先对照后端已有接口，再绑定真实数据，不在前端虚构服务健康率、准确率或工具调用结果。现有会话是内存实现，不应把示例历史记录宣称为数据库持久化。当前指标与日志使用 mock，不应宣称已接入真实生产集群。

建议正式 UI 保留“等待模型 / 工具执行 / 检索完成 / 超时 / 空结果 / 失败”的状态反馈，避免只出现一个无限等待的“正在思考”。来源栏应展示实际召回的文档标识与片段；后端若未返回引用元数据，应先补齐接口，不能将生成文本当作检索证据。

## 当前平台交互

根路径 `/` 默认进入 `/designs/workbench-v2.html`，故障深挖为 `/designs/incident-v2.html`，知识助手为 `/designs/knowledge-v2.html`。历史页面仍可从 `/designs/` 的归档区打开。

当前中转 `https://api.apigoto.com`，模型 `deepseek-flash`；密钥保存在本机加密文件，不写入源码。

平台接口提供告警、日志、上传文档目录、文档内容和流式问答。知识助手支持“知识库优先”和“通用问答”两种模式：知识库优先会先检索 Milvus，资料匹配时依据召回片段回答，资料不足时自动使用通用知识补充并明确标注；通用问答不检索知识库，直接调用模型。请求字段为 `mode=knowledge/general`，缺省为知识库优先。上传成功表示向量索引完成。检索来源是实际召回片段，不代表每个片段都被最终答案引用；L2 距离不等于可信度。

告警和日志当前为后端模拟数据，没有真实时序指标或发布事件。诊断由带工具的 ReactAgent 生成，报告和交接内容保存在浏览器本地。客户端读取流式响应时主动断开属于正常取消，不再记为 RAG 故障。
